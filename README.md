# Курьер Радар

Android-помощник курьера Uber Eats / Wolt (Варшава): читает оффер на экране и показывает поверх него карточку «БЕРИ / СМОТРИ / МИМО» с zł/км и zł/ч. Ничего не нажимает — только подсказывает.

APK собирается GitHub Actions: при PR — файлом в сборке (Artifacts), после мержа в main — в Releases.
